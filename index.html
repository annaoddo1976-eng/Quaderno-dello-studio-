Nota trasparente su iCloud Drive, OneDrive e GitHub Pages:

Per sicurezza, i browser su iPad/Safari e le pagine ospitate su GitHub Pages non possono scrivere silenziosamente in background dentro iCloud Drive o OneDrive senza la tua scelta esplicita. Puoi collegare un file locale (su browser compatibili con File System Access API) oppure salvare/caricare il file Quaderno_Studio_Backup.json tramite Salva su File → iCloud Drive / OneDrive.

Puoi salvare prima una copia dei dati attuali sul dispositivo e poi procedere con il ripristino del backup verificato.
